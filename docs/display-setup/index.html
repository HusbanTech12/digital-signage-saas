1. How connection works (all options)

The TV or LCD is only a screen. A small computer (stick, Pi, mini-PC, or the TV’s own OS) opens your hosted app in a browser.

  1. HDMI in: Stick / Pi / mini-PC plugs into the LCD’s HDMI port (or use the TV’s built-in browser).
  2. Network: Device joins the same store Wi‑Fi (or Ethernet) that can reach your Signage frontend URL.
  3. Pair: Open https://YOUR-APP/pair → TV shows a 6-digit code.
  4. Bind in dashboard: Screens → Enter code → pick location + LCD type (resolution / orientation).
  5. Play: Open https://YOUR-APP/display/SCREEN_ID fullscreen and leave it running.
Offline resilience: If Wi‑Fi drops briefly, the last published menu stays cached on the device so the board does not go blank.

2. Shared pairing & publish steps

Do this once per physical screen, no matter which hardware option you chose.

In the restaurant / store

  1. Power on the LCD/TV and set the correct HDMI input.
  2. Connect the playback device to Wi‑Fi or Ethernet.
  3. Open the pairing URL on that device’s browser:
    https://YOUR-FRONTEND-DOMAIN/pair
    Example:
    https://digital-menu-brai.vercel.app/pair
  4. Write down the 6-digit pairing code on screen.

In the admin dashboard

  1. Sign in → go to Screens (or Stick setup).
  2. Click Enter code, type the 6-digit code, name the screen, assign a Location.
  3. Choose the matching LCD type (e.g. Full HD Landscape 1920×1080, or Portrait for tall menus).
  4. Create/publish a Menu + Template aimed at that screen (landscape design for landscape LCDs).
  5. Copy the screen’s Display URL from Stick setup / Screens.

Back on the TV device

  1. Open the Display URL:
    https://YOUR-FRONTEND-DOMAIN/display/scr_xxxxxxxx
  2. Enter fullscreen (F11, or the browser’s fullscreen control).
  3. Disable sleep, screensaver, and auto-brightness dimming on the stick / OS.
  4. Bookmark the Display URL so a reboot recovers quickly.

4. Option A — Chromium kiosk (Raspberry Pi / mini-PC)

Raspberry Pi 4/5 or Intel NUC-style mini-PC

Recommended Best lock-down

Runs Chromium in true kiosk mode so staff cannot easily leave the menu board. Best for long store hours and multi-location fleets.

  1. Hardware: Raspberry Pi 4/5 (4GB+) or small x86 mini-PC + HDMI cable + power + microSD (Pi) or SSD.
  2. OS: Install Raspberry Pi OS (Desktop) or a light Linux / Windows IoT image. Connect HDMI to the LCD.
  3. Network: Join Wi‑Fi or plug Ethernet; confirm you can open the Signage site in a browser.
  4. Pair once: Open /pair, complete dashboard binding (Section 2).
  5. Kiosk auto-start (Linux / Pi example): create a startup script that launches Chromium fullscreen to the Display URL:
    chromium-browser --kiosk --noerrdialogs --disable-infobars \ --check-for-update-interval=31536000 \ "https://YOUR-FRONTEND-DOMAIN/display/SCREEN_ID"
  6. Autostart: Add that command to ~/.config/autostart/ (desktop entry) or a systemd user service so it runs after boot / power restore.
  7. Disable sleep: Turn off screen blanking and screensaver in OS power settings (or xset s off -dpms on X11).
  8. Optional: Hide mouse cursor, disable desktop notifications, set LCD to fixed 1920×1080 (or your chosen preset).
Windows mini-PC: Create a shortcut to chrome.exe --kiosk "https://…/display/SCREEN_ID" and place it in the Startup folder; set power plan to Never sleep.

5. Option B — Amazon Fire Stick

Fire TV Stick / Fire TV Stick 4K

Budget friendly Fast install

Plug-and-play HDMI stick. Uses the built-in Silk browser. Great for pilots and low-cost stores; less locked than a Pi kiosk (remote can exit the browser).

  1. Insert the Fire Stick into the TV HDMI port. Use the USB power adapter (do not rely on weak TV USB power).
  2. Complete Amazon first-time setup; connect to store Wi‑Fi.
  3. Open Silk: From the Fire TV home screen, find Silk Browser (or search “Silk”).
  4. Go to pair URL:
    https://YOUR-FRONTEND-DOMAIN/pair
  5. On phone/laptop dashboard: Screens → Enter code → location + LCD type.
  6. Open Display URL in Silk (from Stick setup page copy link). Bookmark it in Silk.
  7. Fullscreen: Use Silk’s menu → request desktop site if layout looks mobile, then enter fullscreen.
  8. Disable sleep: Settings → Display & Sounds (or Preferences) → Sleep → set the longest interval / Never if available. Turn off screensavers.
  9. Daily recovery: If the stick reboots, open Silk → Bookmarks → Display URL → fullscreen again.
Tip: Hide the remote after setup, or place the stick behind the TV so guests cannot easily navigate away.

6. Option C — Android TV / Google TV stick

Onn, Xiaomi, NVIDIA Shield, store Android TV sticks

Chrome browser Widely available
  1. Plug stick into HDMI; power with the included adapter.
  2. Finish Google / Android TV setup; join Wi‑Fi.
  3. Install Chrome from Google Play if it is not preinstalled.
  4. In Chrome, open /pair, then complete dashboard pairing.
  5. Open the Display URL; tap the three-dot menu → Fullscreen (or Add to Home / shortcut if the stick supports a web shortcut).
  6. Settings → Device Preferences → Power / Energy saver → disable sleep or set maximum time.
  7. Optional: use an Android “kiosk browser” app from Play Store that locks to one URL (third-party; test before fleet rollout).

7. Option D — Chromecast with Google TV

Chromecast (with remote / Google TV UI)

Same flow as Android TV
  1. HDMI + power; complete Google TV onboarding; join Wi‑Fi.
  2. Open Chrome (or built-in browser) → /pair.
  3. Pair in dashboard; open Display URL; go fullscreen.
  4. Disable sleep under System → Power / Energy. Bookmark Display URL.
  5. Do not rely on phone “Cast tab” for production — use the stick’s own browser so the board survives phone disconnects.
Avoid: Casting a laptop tab as the primary method. Always run the player URL on the stick itself.

8. Option E — Smart TV built-in browser

Samsung / LG / Hisense / TCL web browser

Limited No extra hardware

Works for demos when the TV browser is modern enough. Often weaker for 24/7 use (aggressive sleep, slow engines, hard fullscreen).

  1. Connect TV to Wi‑Fi.
  2. Open the TV’s Internet / Web Browser app.
  3. Navigate to /pair → pair in dashboard → open Display URL.
  4. Switch browser to fullscreen / cinema mode if available.
  5. In TV settings, set Auto Power Off / Eco / Sleep to Off or the maximum.
  6. Save the Display URL as a favorite for faster morning start.
If the layout breaks: the TV browser may be too old. Move to Fire Stick, Android TV, or Pi kiosk.

9. Option F — Windows / Mac mini-PC or laptop

Demo, HQ, or high-end installs

Very reliable Easy remote support
  1. HDMI (or USB-C hub) from PC to LCD.
  2. Install Chrome or Edge. Open /pair, finish dashboard binding.
  3. Create a desktop shortcut:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "https://YOUR-FRONTEND-DOMAIN/display/SCREEN_ID"
    macOS:
    /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --kiosk "https://YOUR-FRONTEND-DOMAIN/display/SCREEN_ID"
  4. Put the shortcut in Startup (Windows) or Login Items (macOS).
  5. Power options: Never sleep when plugged in; disable screen saver.
  6. Optional: use assigned access / kiosk mode (Windows) so only Chrome runs.

10. Option G — Generic Android HDMI box

Low-cost Android set-top boxes

Bulk installs Quality varies
  1. HDMI + power; connect Wi‑Fi or Ethernet.
  2. Install Chrome from Play Store (sideload only if you trust the image).
  3. Same pair → dashboard → Display URL → fullscreen flow as Android TV.
  4. Disable sleep; pin Chrome if the launcher supports app pinning.
  5. Burn-in / heat: ensure ventilation behind the TV; prefer brands with active cooling for 12+ hour days.

11. LCD / TV panel tips

  • Match LCD type in dashboard to the physical panel (Full HD / QHD / 4K, Landscape vs Portrait) before publishing templates.
  • Overscan: If edges are cropped, set TV picture mode to Just Scan / Screen Fit / 1:1 pixel mapping.
  • Brightness: Use a fixed brightness; turn off eco dimming so menus stay readable under store lights.
  • Portrait mounts: Rotate the panel physically and set Orientation = Portrait on the Screen + Template.
  • Commercial vs consumer TVs: commercial displays handle 16+ hour duty cycles better; consumer TVs may sleep or show logos.
  • One URL per screen: each paired screen has its own /display/[screenId] — do not share one URL across unrelated TVs.

12. Go-live checklist

  • LCD powered; correct HDMI input selected
  • Playback device on stable Wi‑Fi / Ethernet
  • Paired via /pair and visible as Online in Screens
  • LCD type (resolution + orientation) matches the panel
  • Menu + template published to this screen
  • Display URL open in fullscreen / kiosk
  • Sleep / screensaver disabled
  • Display URL bookmarked or set to autostart
  • Test: edit a price → confirm TV updates within a few seconds
  • Test: brief Wi‑Fi drop → last menu still visible
